# Void Office Tycoon - Setup Instructions

1. Open your terminal.
2. Clone the repository: `git clone <YOUR_REPO_URL>`
3. Navigate into the folder: `cd <YOUR_REPO_FOLDER>`
4. Navigate to the backend server folder: `cd project/it-project-management/void-office-tycoon/server`
5. Install the backend dependencies: `pip install -r requirements.txt`
6. Start the backend server: `python3 app.py` (leave this running)
7. Open a **second, new terminal window**.
8. Navigate to the frontend client folder: `cd <YOUR_REPO_FOLDER>/project/it-project-management/void-office-tycoon/client`
9. Install the frontend Node modules: `npm install`
10. Start the game client: `npm run dev` (leave this running)
11. Open your web browser (Chrome, Safari, etc.).
12. Go to the URL provided by Vite, usually: `http://localhost:5173`
13. Play the game!
