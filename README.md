# Void Office Tycoon - Setup Instructions

1. Open your terminal.
2. Clone the repository: `git clone <YOUR_REPO_URL>`
3. Navigate into the frontend client folder: `cd <YOUR_REPO_FOLDER>/project/it-project-management/void-office-tycoon/client`
4. Install the Node modules: `npm install`
5. Start the game client: `npm run dev` (leave this running)
6. Open your web browser (Chrome, Safari, etc.).
7. Go to the URL provided by Vite, usually: `http://localhost:5173`
8. Play the game!
